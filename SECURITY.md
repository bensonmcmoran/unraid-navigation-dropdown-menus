# Security Policy

## Reporting a vulnerability

Please do not report suspected security vulnerabilities through a public GitHub issue.

Use GitHub's **Private vulnerability reporting** feature for this repository so the report can be reviewed privately.

Please include:

- affected Navigation Dropdown Menus version;
- affected Unraid OS version;
- a clear description of the issue and potential impact;
- reproduction steps or a proof of concept when appropriate; and
- any suggested mitigation you have identified.

General bugs and feature requests that are not security-sensitive may be filed through GitHub Issues.
